# RFT EtherCAT Interface Software

## Overview

The RFT EtherCAT Interface Software provides a reference implementation for interfacing with RFT Series Force/Torque Sensors via EtherCAT communication.
It enables real-time data acquisition, monitoring, and basic control of the sensor, and is intended for evaluation, integration, and development purposes.
This repository includes both executable files and full source code to support rapid deployment and customization in industrial and research environments.

## Key Features
* Real-time force/torque data acquisition via EtherCAT 
* Sensor status monitoring and visualization 
* Basic configuration interface 
* Data logging for analysis and validation 
* Example implementation for quick integration 
 
## Note
This software is provided as a reference example. Users are encouraged to modify and extend it according to their specific application requirements.
